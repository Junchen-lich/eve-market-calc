# 市场动态与制造核算台 v1.1

面向太空网游玩家的本地优先工具：市场行情查询、工业制造核算、精炼/反应/行星工业、挂单利润核算与角色技能联动。

> **v1.1 更新**：技能名与游戏内完全对齐（会计学/经纪人关系学/工业理论/高级工业理论/批量生产学/提炼学概论/提炼效率理论/实验室运作理论/科学原理/冶金学/研究概论）；制造核算 ME(0–10)/损耗率/TE(0–20)/材料加成下拉化，制造服务费改为作业一次；TE 并入生产时间展示；蓝图搜索改为本地中文名匹配；角色技能补全研究/提炼相关技能。

- 界面全中文，物品只显示中文名，不暴露 typeID
- 金额 2 位小数带千分位，数量输入框统一步进器
- 支持多区服（区服一 / 区服二 / 区服三）与欧服市场行情

## 运行

```bash
node server.js
# 打开 http://localhost:8657
```

仅依赖 Node 内置模块（无第三方包）。HTML 与数据 JSON 均以 `no-cache` 托管，改动后刷新浏览器即生效。

## 数据文件

| 文件 | 内容 |
| --- | --- |
| `market_groups.json` | 市场分组（目录树 / 常用收藏） |
| `item_names.json` | 物品中文名表（typeID → 中文名） |
| `industry.json` | 工业活动耗时 / 材料 / 产物 |
| `pi.json` | 行星工业数据 |
| `blueprints.json` | 蓝图：产物 / 产量 / 材料 |
| `blueprint_times.json` | 蓝图各活动耗时 |
| `universe.json` | 星域 / 星座 / 星系三级宇宙数据（含中文） |

原始数据与构建脚本为本地开发资源（`数据源\`、`开发脚本\`、`项目文档\`），未随仓库推送。

## 文档

开发文档与接口调用资料保存在本地 `项目文档\` 目录，为保护开发细节未随仓库推送。

## 说明

- 第三方市场数据服务无跨域头，页面经本地 `server.js` 代理访问行情与欧服公开合同接口。
- 角色数据库 / 收藏 / 手动记录的生产时间等个人数据保存在程序目录下的「用户数据」文件夹，不随仓库提交。
